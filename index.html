② 需重点补习的知识点

按优先级排列，对应上述个人诊断中的薄弱点

1. 图像变换 Graph Transformations 最高优先

  • 平移：右移 h → x−h；左移 h → x+h；上移 k → +k；下移 k → −k。例如 f(x)=x² 右 2 上 3 ⇒ y=(x−2)²+3，最低点 (2,3)。
  • 反射：关于 x 轴 ⇒ y=−f(x)；关于 y 轴 ⇒ y=f(−x)。
  • 拉伸：沿 y 轴 scale factor a ⇒ y=a·f(x)（纵向整体缩放）。
  • 两步序列：顺序要与参数配套；先拉伸后平移与先平移后拉伸的向量不同，须自查最终式。

2. 多项式 · 因式定理与余数定理 最高优先

  • 因式定理：(x−a) 是 f(x) 的因式 ⇔ f(a)=0。
  • 余数定理：f(x) 除以 (x−a) 的余数为 f(a)。
  • 降次分解：用除法 / 综合除法 / 分组提取一次因式，再对二次因子继续分解；判别式 <0 时实数范围内不可再分。

3. 反函数 Inverse Function 高优先

  • 反函数 ≠ 倒数：f⁻¹(x) 是“逆运算”，不是 1/f(x)！
  • 求法：令 y=f(x) → 互换 x、y → 解出 y → 写出 f⁻¹(x)。
  • 定义域：反函数的定义域 = 原函数的值域；单调（或限定定义域使其一一对应）才能存在反函数。

4. 含参数的圆 Circle with Parameter 高优先

  • 标准方程 (x−a)²+(y−b)²=r²，圆心 (a,b)、半径 r（注意是 r 不是 r²）。
  • 圆上点到圆心距离 = 半径；直径中点 = 圆心；列方程后按要求（如 c>0）取舍根。

5. 二次函数值域与配平方 Completing the Square 中优先

  • x²≥0，故 x²−2≥−2；配平方 (x−p)²+q 直接给出最值与值域（注意定义域限制）。

6. 判别式与二次不等式 中优先

  • 无实根 ⇔ Δ<0；恰一根 ⇔ Δ=0（且须为二次方程，a≠0）。
  • 开口向上时不等式 ≤0 取两根之间闭区间；整数解在闭区间内枚举。

7. 直线与垂直 / 反射规则 / 复合函数 巩固

  • 垂线斜率互为负倒数；联立求交点须逐步消元回代。
  • 复合函数 fg(x)=f(g(x))，定义域由“内层函数值落在外层定义域内”决定，解方程后须舍去超出定义域的根。

第 2 周 · 含参圆 + 直线与垂直（Q11 / Q12 重做）
  • 圆：默写 (x−a)²+(y−b)²=r²；把圆心 (2c,−c)、半径 5c、点 (−2,3c) 代入得 (2+2c)²+(4c)²=25c²，解出 c=2（c>0）；再用中点公式求直径另一端 M=(10,−10)。
  • 直线：垂线斜率为负倒数 5/3；点斜式后必须化为整数系数一般式 ax+by+c=0，并回代点 (4,2) 验算。
  • 任务：完成【圆】【直线】标签下全部题目；把 Q11(b)、Q12 限时各重做一遍并写满全步骤。
第 3 周 · 多项式完整链条 + 带定义域的反函数
  • 固定五步链：因式定理 f(2)=0 建一式 → 余数定理 f(−1)=−12 建二式 → 联立解 a、b → 长除 / 分组分解降次 → 判别式判断能否再分。以 Q14、Q15 为模板练到能独立写到底。
  • 反函数：f(x)=(x−3)²+1（x≥3）⇒ f⁻¹(x)=3+√(x−1)，定义域 = 原函数值域 x≥1；解 fg(x)=5 后必须用 g(x)≥3 舍去 x=1。
  • 作图题规范：先求全部 x 轴交点与 y 轴截距，再画曲线、标坐标，不能只写一个 (0,12)。
  • 任务：完成【多项式】【反函数】【复合函数】【值域】标签下全部题目。
第 4 周（月考前）· 限时整套模拟 + 结果核验清单
